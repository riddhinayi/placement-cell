# Placement Cell Management System
A full-stack web application developed using Python and Flask to automate and manage campus placement activities efficiently. The platform connects students, recruiters, and placement coordinators through a centralized system for placement drive management, applications, interview scheduling, and placement tracking.

# Project Overview
The Placement Cell Management System simplifies the traditional placement process by digitizing recruitment workflows within educational institutions. The system provides role-based access for Admins, Students, and Recruiters, ensuring smooth communication and efficient placement operations.
                         
This project is designed for colleges and universities to manage placement activities, maintain student records, and streamline recruitment procedures through a secure and scalable web application.

## System Workflow

# Step 1 — Student Registration
Students create accounts and complete profiles with:
Academic Details
Skills
Resume
Contact Information

# Step 2 — Placement Drive Creation
Recruiters create job drives including:
Job Role
Salary Package
Eligibility Criteria
Interview Details

# Step 3 — Admin Approval
The placement coordinator reviews and approves placement drives before publishing.

# Step 4 — Student Applications
Eligible students apply for placement opportunities directly through the portal.

# Step 5 — Shortlisting & Interviews
Recruiters shortlist candidates and schedule interview rounds.

# Step 6 — Final Placement Result
Selected students are marked as placed and reports are generated automatically.
